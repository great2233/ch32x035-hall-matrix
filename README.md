# CH32X035G8R · 8×8 霍尔矩阵磁场可视化系统

基于 CH32X035（RISC-V）与 64 个 SS49E 线性霍尔传感器构建的 **8×8 磁场强度采集与可视化** 系统。固件逐行选通、逐列 ADC 采样，经 USB CDC 虚拟串口将原始/校准后的磁场强度矩阵实时发送至上位机（Web Serial / Python / Qt），支持逐点零场校准与温漂补偿。

---

## 1. 功能特性

- **8×8 霍尔矩阵扫描**：行选通（SS8550 PNP 驱动）+ 列 ADC（12bit）逐行采集 64 点
- **磁场强度换算**：按 SS49E 特性将 ADC 换算为高斯（G），支持逐点校准
- **逐点零场校准**：64 点独立偏移，一键校准并存入 Flash（上电自动加载）
- **温漂补偿**：基于 CH32X035 内部温度传感器，对温度变化量进行磁场补偿
- **USB CDC 虚拟串口**：115200 波特率，命令交互 + 周期数据输出
- **多端上位机**：
  - Web Serial 版（推荐，纯浏览器直连串口，无依赖）
  - Python + Qt 版（PySide6 桌面应用）
  - Python HTTP 网页版（备选）
- **参数在线调节**：扫描周期、行延时、采样平均次数、温漂系数等，命令实时设置并 Flash 持久化

## 2. 硬件

### 2.1 系统构成

```
                    +----------------------------+
  行驱动(8) ───────►│  SS8550 PNP ×8             │
  PB0-PB9 低电平选通 │  为对应行 SS49E 供电         │
                    │                            │
                    │   8×8 SS49E 线性霍尔阵列      │
                    │   (64 个, 每点输出模拟电压)    │
                    │                            │
  列采集(8) ◄───────│  PA0-PA7 → ADC1 CH0-CH7     │
  ADC 读取霍尔输出    │                            │
                    +----------------------------+
                              │
                         USB CDC (PC16/PC17)
                              │
                    上位机 (Web Serial / Python / Qt)
```

- 霍尔传感器：**SS49E** 线性霍尔，模拟电压输出，量程约 ±640 G
- 行开关：**SS8550** PNP 三极管，MCU 输出低电平选通该行霍尔供电
- MCU：**CH32X035G8R**，ADC1 12 位，内置 USB FS 与内部温度传感器

### 4.2 串口命令

USB CDC 虚拟串口（115200）或 USART1 输入命令，回车执行：

| 命令 | 功能 |
|------|------|
| `hall` | 扫描一次并发送原始 ADC 矩阵（`=== Hall Matrix`） |
| `field` | 扫描一次并发送磁场强度矩阵（G，含校准与温漂） |
| `cal` | 回传当前校准表（`=== Cal Table`） |
| `cal_zero` | **零磁场校准**：记录 64 点偏移 + 温度基准并写入 Flash |
| `cal_reset` | 清除校准表并保存 |
| `temp` | 查看内部温度传感器信息（当前/基准 ADC、使能、系数） |
| `sysinfo` | 芯片信息（ChipID、时钟、USB 枚举状态） |
| `status` | 状态（运行计数、扫描计数、当前参数） |
| `i [val]` | 读取/设置参数 `i` |
| `param` | 列出全部参数 |
| `param set <name> <val>` | 设置参数并写入 Flash |
| `param save` | 手动保存参数到 Flash |
| `param def` | 恢复默认值 |
| `reset` | 软件复位 |
| `help` | 命令帮助 |

### 4.3 运行参数（Flash 持久化）

| 参数 | 类型 | 默认 | 范围 | 说明 |
|------|------|------|------|------|
| `interval` | u16 | 300 | 50–5000 | 扫描发送周期 (ms) |
| `row_delay` | u16 | 100 | 1–5000 | 行选通供电稳定延时 (µs) |
| `close_delay` | u16 | 50 | 0–2000 | 行关闭延时 (µs) |
| `samples` | u8 | 4 | 1–16 | 每点 ADC 采样平均次数 |
| `field_zero` | u16 | 2048 | 0–4095 | SS49E 零磁场 ADC 中点（备用换算） |
| `field_k` | u16 | 872 | 1–10000 | 磁场换算系数 |
| `temp_en` | u8 | 0 | 0/1 | 温漂补偿使能 |
| `temp_coeff` | int16 | 0 | ±1000 | 温漂补偿系数 |
| `i` / `mode` / `thresh` / `count` | — | 0/0/100/0 | — | 通用用户参数 |

设置示例：`param set interval 200`、`param set samples 8`、`param set temp_en 1`

### 4.4 数据协议（115200, 8N1）

上位机解析的文本帧（每条命令回显亦走此通道）：

```
\r\n=== Hall Matrix (8x8) ===\r\n     ← 原始 ADC 矩阵
0001 0002 ... 0008\r\n                ← 8 行，每行 8 个 0-4095
...
==========================\r\n

=== Field Matrix (G) ===\r\n          ← 磁场强度矩阵
 +12.3  -3.4 ...\r\n                  ← 带符号，一位小数，单位 G
============================\r\n

=== Cal Table ===\r\n                 ← 校准表
0000 0000 ...\r\n                     ← 64 点 u16 偏移
====================\r\n

--- Params ---\r\n                    ← 参数回显
  interval = 300\r\n
  ...
```

### 4.5 磁场换算与逐点校准

```
B(G) = (adc - cal[row][col]) × field_k / 1000
```

- `cal[row][col]`：该点零磁场校准偏移（`cal_zero` 写入，逐点不同以消除传感器差异）
- `field_k`：每 ADC 对应的高斯比例（默认按 SS49E 典型值推导）

SS49E 典型参数：供电 5V、灵敏度约 **1.4 mV/G**、零场输出约 2.5V、量程约 **±640 G**。
默认 `field_k=872` 对应「分压 5V→3.3V + 零场 ADC≈2048」的假设，**若硬件分压不同需重新标定**。

### 4.6 温漂补偿

- 数据源：CH32X035 **内部温度传感器**（ADC 通道 16），扫描后读取
- 原理：校准时记录温度基准 `ts_ref`，此后按温度变化量补偿：
  ```
  B += (ts_now - ts_ref) × temp_coeff / 1000
  ```
  仅补偿相对温漂，无需绝对温度公式
- `temp_en=1` 才读取温度，`TS_Read` 带超时保护（通道无效不会卡死主循环）
- ⚠️ 补偿系数方向由 `temp_coeff` 符号决定，默认关闭，需实测标定

### 4.7 Flash 参数存储

- 地址：`0x0800F000`（末页 256 字节）
- 布局：参数块 32 字节 + 校准表 `cal[64]` 128 字节
- 魔数 `0x50415201` 校验有效性；参数/校准非法时自动恢复默认

## 5. 上位机

### 5.1 Web Serial 版（推荐）

单文件 `HostApp/web_serial.html`，使用浏览器原生 **Web Serial API** 直连串口，**无需 Python/服务器/驱动安装**。

**用法**：
1. 用 **Chrome 或 Edge** 双击打开 `web_serial.html`
2. 点「连接串口」→ 系统弹窗中选择设备（USB 虚拟串口，如 **COM39**）
3. 自动获取参数与校准表，热力图实时刷新

**功能**：
- 热力图 + 侧边色条（蓝→红双色渐变，DPR 高清）
- **三档显示**：原始值(ADC) / 校准后(ADC) / 校准后高斯(G)
- 参数滑块：扫描周期、行/关延时、采样平均、温漂使能/系数
- 「**零磁场校准**」一键校准并回读校准表
- 「磁场强度 / 原始ADC」快捷命令、自由命令框、实时日志
- 读取流自愈：异常/超时自动重建，偶发断流自动恢复

### 5.2 Python + Qt 版

`HostApp/main.py`（PySide6 桌面应用）：

```
py -3.12 -m pip install -r HostApp/requirements.txt
py -3.12 HostApp/main.py            # 启动界面
py -3.12 HostApp/main.py --selftest # 协议自测
```

### 5.3 Python HTTP 网页版（备选）

```
HostApp\web\启动网页上位机.bat      # 双击：启动服务器并打开浏览器
# 或 py -3.12 HostApp/web/server.py
```

浏览器访问 `http://127.0.0.1:8080`。此版需串口空闲（勿与 Web Serial 同时占用同一端口）。

### 5.4 校准流程（零磁场校准）

1. 连接串口，**确保矩阵区域无磁场**（磁场越均匀越好）
2. 点击「零磁场校准」按钮（或发送命令 `cal_zero`）
3. 固件记录 64 点零场偏移 + 温度基准，**写入 Flash**
4. 显示切换到「校准后高斯(G)」查看逐点校准后的磁场分布
5. 校准可反复执行；`cal_reset` 可清除

## 6. 快速开始

1. 编译烧录固件（§4.1）
2. 双击 `HostApp/web_serial.html`，Chrome/Edge 打开
3. 点「连接串口」，弹窗中选择 USB 虚拟串口（如 COM39）
4. 观察热力图数据刷新；确认日志出现「校准表已更新」
5. 无磁场状态下点「零磁场校准」
6. 切换显示为「校准后高斯(G)」，开始测量/观察磁场分布
7. 需要时用滑块或 `param set` 调节扫描周期等参数

## 7. 常见问题排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 连接串口失败 / 需连两次 | 端口被占用或未释放 | 关闭串口助手/Python 上位机；上位机已自动重试 3 次 |
| 能收到字节但无矩阵帧 | 旧固件或解析状态异常 | 重新烧录最新固件；新版本解析已自愈 |
| 连接后 3 秒无数据 | USB 未枚举 / 选错端口 | 确认选择 CDC 虚拟串口、波特率 115200；查看日志提示 |
| 数值为 0 或不变 | 未连接 / 行未选通 | 检查供电与行驱动；确认已校准 |
| 磁场读数偏大/偏小 | 分压比例与 `field_k` 不符 | 用已知磁场标定 `param set field_k` |
| 温漂补偿无效 | 内部温度通道不可用或未标定 | 确认 `temp_en=1`、`temp_coeff` 非零，按手册核实通道 16 |
| 网页版打不开 | 未启动 server 或直接双击了 HTML | 运行 `启动网页上位机.bat`，访问 http://127.0.0.1:8080 |

## 8. 附录

### 8.1 换算与默认值推导

默认 `field_k=872` 推导（SS49E 灵敏度 S=1.4 mV/G，分压比 K=3.3/5，ADC 参考 3.3V）：

```
adc = Vhall × K / 3.3 × 4096 = Vhall × 819.2   (Vhall 单位 V)
B(G) = (Vhall − 2.5V) / S
⇒ B(G) ≈ (adc − 2048) × 0.872
⇒ field_k = 872  (B = Δadc × field_k / 1000)
```

### 8.2 主要版本

- 固件：矩阵扫描 + USB CDC + 磁场换算 + 逐点校准 + 温漂补偿
- 上位机：Web Serial（原生）/ Qt（PySide6）/ Web（HTTP）
